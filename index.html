认知转变

核心观点

⛔ 旧思路：建系统

  • 依赖IT/Data部门排期开发
  • 需求沟通 → 开发 → 测试 → 上线，周期半年起
  • 各方资源有限，排队等待
  • 系统僵化，需求变了再改又要排期
→

✅ 新思路：造 Skill

  • IR每个人自己用AI助手（Cowork）解决重复工作
  • 不需要写代码，对话即可生成
  • 不依赖任何外部资源，即做即用
  • 需求变了随时调整，灵活响应

a · 潜在LP挖掘与拓展
手工调研与分析
现状：依赖人脉和手工信息检索
远期探索
AI机会：公开信息自动监测、LP画像匹配推荐。此项为募资核心领域，AI介入空间目前有限，建议放入远期探索。
b · 募资签约与文件流转
b-1
募集进度管理
手工跟踪"接洽→尽调→谈判→KYC→签约"全流程
近期可做
AI机会：进度状态自动追踪与提醒，关键节点预警。
Skill思路：基于Excel进度表自动生成进度报告和待办提醒。
b-2
签约文件检查与追补
手工核查涉及的几十份文件齐备性，向LP追补
近期可做
AI机会：自动比对文件清单，识别缺失项，生成追补邮件草稿。
Skill思路：输入LP签约文件夹 → AI核查齐备性 → 输出缺失清单+追补邮件。
b-3
内部文件流转
手工将签约文件发送给法务/财务
远期探索
AI机会：需结合内部系统集成，目前手工转发即可，优先级较低。
c · 募后管理与服务 — 最大痛点区
c-1
LP信息管理
Excel维护70家机构LP/160家个人LP，每家22字段；1777+联系人每人25字段
现在就能做
AI机会：数据清洗标准化、变更提醒、批量格式转换。
Cowork Skill：将现有Excel数据清洗为青鸟系统导入格式，一次性激活分发平台。
备注：青鸟系统上线后仍需人工操作（比以前方便，但还不能一句话发邮件）。后续可探索将青鸟系统接入MCP，实现对话式直接完成分发任务。
c-2
报告分发
年耗27+工作日手工制表
包含两个独立需求 ↓
现在就能做
需求①：日常水印加密（Ad-hoc）
任何IR同事随时要发文件给LP，都需手动打个性化水印+加密。→ Cowork Skill，所有IR同事可用，从10分钟/份→30秒。

需求②：定期批量分发（季度/半年度）
青鸟系统已在测试阶段（Data组开发），卡点是LP初始数据导入 → AI辅助数据整理解决。

注意：两个需求独立，水印Skill不依赖青鸟系统。
c-3
个性化报表生成
偿二代险资表格（~5-10家）、LP定制报告（~20份/季度），按不同LP模板手工填充
现在就能做
偿二代报表：IR从各部门获取Excel数据 → 手动填入各险资LP的固定模板。每家模板不同但固定，最适合自动化。
LP定制报告：来源为邮件信息及Excel数据，按不同LP模板自动排版生成初稿。
Cowork Skill：上传原始数据+LP模板 → AI自动填充生成。
使用者：负责对应险资LP/机构LP的同事各自使用。
c-4
LP系统填报
手工填报13家LP的18个系统，各系统100-300项目/20-70字段
近期可做
AI机会：从内部数据自动提取对应字段，预填各LP系统的填报内容。
复杂度：中等——需要逐个理解各LP系统的字段映射关系。
使用者：负责各LP系统填报的对接人。
c-5
LP会议协同管理
Syndication call / dial-in 通知起草、材料分发、LP问题清单整理、会议纪要等
近期可做
AI机会：自动起草会议通知邮件（含dial-in信息）、整理LP问题清单、会议后自动生成纪要和待办。
Skill思路：输入会议基本信息 → AI生成通知及分发材料；上传录音/笔记 → AI整理纪要。
d · LP沟通与关系维护
d-1
节假日问候
手动编辑发送，难以个性化
近期可做
AI机会：批量生成个性化问候（考虑LP背景、历史互动、时令节点）。
Skill思路：输入LP清单 → AI按每个LP的特点生成个性化问候文案。
d-2
互动频率监测
缺乏有效工具跟踪与各LP的互动频率
远期探索
AI机会：需要数据积累后才能实现。基于邮件/会议记录自动统计互动频率，预警"冷落"的重要LP。
d-3
国内Insights分享至QFLP
手动整理分享内容
近期可做
AI机会：从内部信息源自动提取、翻译、整理insights摘要。
Skill思路：输入原始内容 → AI整理为适合QFLP阅读的简报格式。
内部知识储备
Dashboard数据汇总
新基金募资进展、LP投资全景等
远期探索
需要跨系统数据集成后才能实现自动化Dashboard生成。

依赖IR同事记忆和手动翻找
远期探索
需要积累结构化LP数据后，AI可自动追踪和预警重要变化。

Agent时代，最大的变化是——

不需要建系统了。每个IR同事自己就能用AI解决重复工作。
先从最痛的几件事开始，逐步推进。

下一步行动

1

做一个Demo

以"PDF水印+加密"为示范Skill，演示Cowork如何在30秒内完成过去10分钟的手工操作。顺带演示加完水印后一键在Outlook草稿箱生成各LP对应邮件并自动附上文件，检查无误后直接发送。

2

各自探索AI路径

每位IR同事针对自己负责的工作，用Cowork探索AI能帮上忙的切入点——因为只有本人最了解自己的业务细节和实际痛点。

3

月度复盘迭代

每月汇总各Skill的使用效果和节省时间，持续优化。按路线图推进到下一批场景。
